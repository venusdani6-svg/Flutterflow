icoccha 管理画面 — 管理者マニュアル

版: 1.0（フェーズ8 納品）　プロジェクト: icoccha-admin-dashboard

1. はじめに

本マニュアルは icoccha 管理画面（Web）の操作手順です。管理データは Cloud Functions 経由でのみ操作します。

項目推奨
ブラウザGoogle Chrome 最新版
画面幅1024px 以上
リージョンasia-northeast1

2. ログイン

  1. /adminLoginPage を開く
  2. 管理者メール/パスワードでログイン
  3. users/{uid}.role_admin == "admin" が必須

非管理者は「管理者権限がありません」と表示されサインアウトされます。

4. 主要操作

4.1 ダッシュボード

KPI（本日登録・予約・売上）、ユーザータイプグラフ、月次売上、監査ログを表示。adminGetDashboardStats を使用。

4.2 KYC 審査

KYC審査管理 → pending ユーザーを承認/却下。モバイルは users/{uid}.kyc_status を参照して機能解放。

4.3 予約詳細

決済情報パネルでチップ合計・強制キャンセル。adminGetTipsByReservation / adminForceCancel

4.4 Stripe ログ（3 フィルタ）

イベント種別・予約 ID・日付範囲で検索。adminGetStripeLogs

4.5 出金申請（4 ステータス）

pending / approved / on_hold / rejected。pending から承認・保留・否認。

4.6 バナー → モバイル Home

バナー編集後、getAppHomeData でモバイルに反映。管理画面の「モバイル連携プレビュー」で確認可。

4.7 システム設定（タブ別保存）

タブ保存ボタン
基本設定基本設定を保存する
キャスト報酬キャスト報酬設定を保存する
アフィリエイトアフィリエイト設定を保存する
提供エリア提供エリア設定を保存する
タクシー代タクシー代設定を保存する

4.8 cocoten OFF

基本設定で cocoten を OFF → 保存。getAppFeatureFlags で cocoten: false → モバイルのココ店タブ非表示。

5. 管理者の種類（フェーズ7）

種別admin_role説明
スーパー管理者super_admin全画面・全データ
都道府県管理者prefecture_admin画面権限 + 管轄都道府県

スーパー管理者は管理者詳細 →「管理者権限設定」で他管理者の権限を編集。
