# icoccha 管理画面 — 管理者マニュアル

**版:** 1.0（フェーズ8 納品）  
**プロジェクト ID:** icoccha-admin-dashboard  
**対象読者:** スーパー管理者・都道府県管理者  

---

## 1. はじめに

本マニュアルは icoccha **管理画面（Web）** の操作手順です。  
管理データはすべて **Cloud Functions** 経由で操作し、Firestore をクライアントから直接読み書きしません（自分の `users/{uid}` のみ例外）。

### 1.1 動作環境

| 項目 | 推奨 |
|------|------|
| ブラウザ | Google Chrome 最新版 |
| 画面幅 | 1024px 以上（スマホ幅は非対応） |
| ネットワーク | Firebase / Cloud Functions へ接続可 |

### 1.2 管理者の種類

| 種別 | `admin_role` | 説明 |
|------|--------------|------|
| スーパー管理者 | `super_admin` | 全画面・全データ |
| 都道府県管理者 | `prefecture_admin` | 画面権限 + 管轄都道府県で制限 |

都道府県管理者は `admin_permissions`（画面 ON/OFF）と `managed_prefectures`（データ範囲）で制御されます。

---

## 2. ログイン・ログアウト

### 2.1 ログイン

1. 管理画面 URL を開く（例: `/adminLoginPage`）
2. Firebase Auth で登録済みの **管理者メール/パスワード** を入力
3. 「ログイン」をクリック

**注意:** `users/{uid}.role_admin` が `"admin"` でない場合はログイン拒否されます。

### 2.2 ログアウト

画面右上またはメニューからサインアウト（実装箇所はビルドにより異なります）。

---

## 3. 画面一覧とメニュー

左サイドメニューから各機能に移動します。表示される項目は **権限** により異なります。

| メニュー | 権限キー | 主な操作 |
|----------|----------|----------|
| ダッシュボード | dashboard | KPI・グラフ確認 |
| ユーザー管理 | user_management | ゲスト/キャスト/スタッフ/管理者一覧 |
| 予約管理 | reservations | 予約一覧・詳細・強制キャンセル |
| 決済・台帳管理 | payment_ledger | 台帳・Stripe ログ |
| 出金申請管理 | withdrawal | 出金承認・保留・否認 |
| KYC審査管理 | kyc | 本人確認の承認/却下 |
| 通報管理 | reports | 通報の確認・解決 |
| アフィリエイト管理 | affiliate | 紹介者・報酬率 |
| ココ店管理 | cocoten | ココ店一覧（機能フラグ連動） |
| お仕事掲示板管理 | job_board | 掲示板管理 |
| バナー広告管理 | banners | Home バナー編集 |
| システム設定管理 | system_settings | 各種設定・お知らせ・ガイドライン |
| 監査ログ管理 | audit_logs | 操作履歴 |

## 4. ダッシュボード

ログイン後の初期画面です。

- **本日の新規登録数 / 予約数 / 売上** — Firestore 集計（`adminGetDashboardStats`）
- **ユーザータイプ円グラフ** — ゲスト・キャスト・スタッフ
- **月次売上グラフ** — `monthly_sales` コレクション
- **直近アクティビティ** — 監査ログ最新 5 件

都道府県管理者は管轄都道府県のデータのみ集計されます。

---

## 5. ユーザー管理

### 5.1 一覧

- ロール別リスト（キャスト / スタッフ / ゲスト / 管理者）
- 検索（メール・表示名）、ソート、ページネーション
- 凍結ユーザーのフィルタ

### 5.2 詳細

- プロフィール表示
- **凍結 / 凍結解除** — `adminToggleFreeze`
- **強制削除** — `adminForceDeleteUser`（確認ダイアログあり）
- キャスト: アフィリエイト報酬率の編集
- 管理者: **管理者権限設定**（スーパー管理者のみ）

### 5.3 管理者権限設定（スーパー管理者のみ）

管理者詳細画面で以下を設定し「権限を保存」:

- **管理者アカウント種別** — スーパー / 都道府県別
- **画面権限** — 各メニューの ON/OFF
- **管轄都道府県** — 都道府県別管理者の場合

---

## 6. KYC 審査

1. **KYC審査管理** を開く（pending のみ表示）
2. 対象ユーザーを選択 → **承認** または **却下**
3. Firestore `users/{uid}.kyc_status` が `approved` / `rejected` に更新

**モバイル連携:** アプリは `users/{uid}.kyc_status` を参照し、承認後に機能制限を解除します。

---

## 7. 予約管理

### 7.1 一覧

ステータス・検索・ページネーションで予約を表示。

### 7.2 詳細 — 決済情報パネル

- 基本料金・タクシー代・スタッフ料金・合計
- **チップ合計**（ledger `type: tip` から集計）
- **強制キャンセル** — 確認後 `status: cancelled`

URL 例: `/reservationdetailsPage?reservationId={ID}`

---

## 8. 決済・台帳管理

3 タブ構成:

| タブ | 内容 |
|------|------|
| 台帳 | payment / refund / tip 等 |
| Stripe ログ | Webhook イベントログ |
| （予約紐付け） | 予約 ID フィルタ可 |

### Stripe ログのフィルタ（3 種）

1. **イベント種別** — payment_intent.succeeded 等
2. **予約 ID**
3. **日付範囲** — 開始日・終了日

---

## 9. 出金申請管理

4 ステータス:

| ステータス | 意味 | 操作 |
|------------|------|------|
| pending | 申請中 | 承認 / 保留 / 否認 |
| approved | 承認済み | 参照のみ |
| on_hold | 保留 | 参照のみ |
| rejected | 否認 | 参照のみ |

## 10. バナー・コンテンツ

### 10.1 バナー広告

- タイトル、画像 URL、リンク URL、有効フラグ、表示順

システム設定管理ハブから:

- **お知らせ管理** — 一覧・作成・公開フラグ
- **ガイドライン編集** — 本文の編集・保存

## 11. システム設定

**システム設定管理 → システム設定** で 5 タブ。各タブに **個別の保存ボタン** があります。

| タブ | 保存ボタン | Firestore セクション |
|------|------------|---------------------|
| 基本設定 | 基本設定を保存する | `settings`, `features_enabled` |
| キャスト報酬 | キャスト報酬設定を保存する | `rewards` |
| アフィリエイト | アフィリエイト設定を保存する | `affiliate` |
| 提供エリア | 提供エリア設定を保存する | `service_areas` |
| タクシー代 | タクシー代設定を保存する | `taxi` |

### 機能フラグ（features_enabled）

| キー | 効果 |
|------|------|
| cocoten | モバイルのココ店タブ表示 |
| staff / staff_security | スタッフ関連 |
| staff_shuttle | 送迎スタッフ |
| affiliate | アフィリエイト |

**cocoten を OFF** にすると、モバイルアプリでココ店タブが非表示になります。

### モバイル連携プレビュー

システム設定管理ハブ → **モバイル連携プレビュー**  
バナー・機能フラグ・Stripe Connect 状態をモバイルと同じ API で確認できます。

---

## 12. 監査ログ

管理者操作（KYC、凍結、削除、予約キャンセル、出金審査等）は `audit_logs` に記録されます。  
**監査ログ管理** で一覧確認できます。

---

## 13. トラブルシューティング

| 症状 | 対処 |
|------|------|
| ログインできない | `role_admin: admin` を Firestore で確認 |
| API エラー | Functions デプロイ・リージョン `asia-northeast1` を確認 |
| データが 0 件 | Firestore にテストデータがあるか確認 |
| 都道府県管理者でデータが見えない | `prefecture` フィールド・管轄都道府県を確認 |
| モバイルに反映されない | `getAppHomeData` / `getAppFeatureFlags` の再取得 |

詳細なデプロイ手順: `firebase/DEPLOYMENT_GUIDE.md`  
受け入れテスト: `docs/ACCEPTANCE_TEST_CHECKLIST.md`
