## シーン詳細

### 0:00 オープニング（30秒）

- タイトルカード: 「icoccha 管理画面 デモ」
- ナレーション: プロジェクト名、対象（MS2/MS3）、本日のデモ範囲

### 0:30 非管理者ログイン拒否（1分）【#1】

1. ログイン画面を表示
2. 一般ユーザーでログイン試行
3. エラーダイアログ → ログアウトを見せる

**ナレーション例:** 「管理者以外はアクセスできません。」

### 1:30 ダッシュボード実データ（1.5分）【#2】

1. 管理者でログイン
2. KPI カード（登録数・予約・売上）をズーム
3. グラフ・アクティビティログをスクロール

**ナレーション例:** 「すべて Cloud Functions から取得した実データです。」

### 3:00 KYC 承認（1.5分）【#3】

1. KYC審査管理を開く
2. pending ユーザーを承認
3. （可能なら）モバイルアプリで制限解除を見せる

**ナレーション例:** 「承認後、kyc_status が approved になりアプリが解放されます。」

### 4:30 予約詳細（2分）【#5, #6】

1. 予約一覧 → 詳細
2. チップ合計・決済ブロックを表示
3. 強制キャンセル → 確認 → ステータス変更

### 6:30 Stripe ログ（1.5分）【#4】

1. 決済・台帳管理 → Stripe ログタブ
2. イベント種別フィルタ
3. 予約 ID フィルタ
4. 日付範囲フィルタ

### 8:00 出金申請（1.5分）【#7】

1. 4 ステータスタブを順に表示
2. pending から承認操作

### 9:30 バナー（1分）【#8】

1. バナー編集・保存
2. モバイル連携プレビューで再取得

### 10:30 設定タブ保存（1分）【#9】

1. システム設定の 1 タブだけ変更して保存
2. SnackBar 成功を見せる

### 11:30 cocoten OFF（1分）【#10】

1. cocoten スイッチ OFF → 基本設定保存
2. モバイル連携プレビューで cocoten: false

### 12:30 権限（任意・1分）

1. 都道府県管理者のメニュー制限
2. 管理者詳細での権限編集（スーパー管理者）

### 13:30 クロージング（30秒）

- 納品物一覧: 管理画面、マニュアル PDF、デプロイ手順、本動画
- 問い合わせ先
